## Shared and generic symbols

- PostgreSQL represents the EF Core/Npgsql database concern; Redis identifies the Redis tier, not HybridCache branding.
- Aspire uses a clearly labelled shared .NET platform mark (the same icon as .NET), not a dedicated Aspire logo.
- `category-validation.svg`, `category-versioning.svg` and `category-testing.svg` are original neutral outline symbols, not official FluentValidation, Asp.Versioning, Shouldly, NSubstitute, Respawn or NetArchTest logos. They inherit this repository’s MIT license.
- xUnit.net’s logo is unmodified and used only to refer to xUnit.net, as its notice requires.
- The existing project logo remains unchanged. Architecture figures are editable repository-owned SVGs, with theme-aware neutral panels and consistent semantic colors.
